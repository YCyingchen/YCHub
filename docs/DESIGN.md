# YCHub 设计规范（v0.1）

Pixso 文件：`ubl06giV8AkNlgbUlFTrnA`（页面 1 · 画板「YCHub · 主界面」1440×900）

## 一、定位

Win11 的秩序感 + Linux 文件管理的高效，做成一套属于 YC 的界面。

- **Win11 借什么**：命令栏、圆角、细腻的灰阶层级、选中态、克制的强调色
- **Linux 借什么**：双栏、路径面包屑、权限/属主可见、挂载点、符号链接标记、快捷键
- **不借什么**：Fluent 的亚克力噪点、过多的图标按钮、把设置拆成几十页

## 三、尺寸与字体

- 圆角：窗口内面板 12 / 控件 9–10 / 标签 10 / 图标块 8
- 行高：列表行 52；导航项 36；命令栏 56；状态栏 28
- 间距：4 的倍数，主要用 8 / 12 / 16 / 20
- 字体：中文 Microsoft YaHei / 英文 Inter；字号 11（辅助）/ 12（正文次）/ 13（正文）/ 15（标题）/ 19（品牌）

对齐规则（画板与实现都必须遵守）：

- 区块标题左对齐，不居中：桌面内容区 x=320 起，移动端 x=20 起；设置左栏导航 x=32，移动设置列表项 x=40
- 卡片内文字左对齐：卡片 x=20 时文字 x=36；行内主标题与副标题同一左边界
- 表单主按钮固定在底部：移动设置子页「保存」位于 y=760（高 46、左右 20），不跟随内容浮动
- 文件类型图标：32×32 圆角色块，内嵌 10px 类型字母（文件夹 `D`、存储 `S`、图片 `IMG`、音频 `M4A`、文档 `DOC`），字母在色块内水平垂直居中；同一类型只出现一个字母，不允许叠字
- 只有分页提示、空状态标题、底部版本号、品牌页标题允许整行居中；其余文本一律左对齐或右对齐到固定列

- 导航分区：快速访问（我的文件 / 最近使用 / 标签 / 收藏）、存储空间（各卷 / 挂载点）、工具（分享链接 / 传输任务 / 回收站）、设置
- 命令栏：前进·后退、面包屑、搜索、三种视图（图标 / 列表 / 分栏）、更多

- 详情：预览图、名称与类型、彩色标签、属性（类型/尺寸/位置/修改/权限）、版本历史（时间 + 大小 + 恢复）、主操作「打开」+ 次操作「分享 / 下载」
- 状态栏：`8 项 · 2 个文件夹 · 6 个文件 · 已选 1 项`，右侧显示当前筛选

## 五、独特功能（写进界面的 YC 特色）

1. **彩色标签 + 按标签筛选**（列表、详情、状态栏联动）
2. **版本历史**：每个文件最多保留 N 个版本，详情面板直接回滚
3. **双栏对拷**：同屏两个目录，拖拽复制/移动
4. **命令面板**（Ctrl+K）：跳转、执行操作、搜索标签
5. **快速预览**（空格）：不离开列表看图片/视频/文本
6. **权限可见**：644 · ceshi 这类信息直接在详情里，不藏进弹窗
7. **传输队列**：底部抽屉，不打断浏览

## 六、Vue 实现映射

| 设计区块 | 组件 | 状态 |
|---|---|---|
| 导航 | `AppSidebar.vue` | 选中项、分组、折叠 |
| 命令栏 | `CommandBar.vue` | 路径栈、搜索词、视图模式 |
| 列表 | `FileList.vue` + `FileRow.vue` | 排序、多选、拖拽 |
| 详情 | `DetailsPane.vue` | 选中文件、标签、版本 |
| 状态栏 | `StatusBar.vue` | 计数、选中、筛选 |
| 标签 pill | `TagPill.vue` | name + color |
| 版本行 | `VersionRow.vue` | time / size / restore |

实现要点：
- 全部用 CSS 变量（`--yc-accent` 等），换主题只改变量
- 不引 UI 组件库，保证风格独立
- 列表用虚拟滚动（`@vueuse/core` 或自研），万级文件不卡
- 图标用内联 SVG sprite，不依赖图标字体

## 八、分享管理与多域名

**分享管理（桌面）**

- 顶部统计：全部分享 / 有效 / 即将到期 / 已过期
- 筛选：全部、有效、即将到期、已过期、已停用；右侧「主用：域名」下拉
- 每条分享：复选框、名称、链接、访问次数/有效期/创建时间、状态、备用域名数量、复制 / 编辑 / 删除
- 选中后底部出现批量条：批量停用、批量删除
- 移动端同样结构：标题「分享管理」、域名条（主用 + 备用切换）、卡片内编辑 / 停用 / 删除

**多域名规则**

- 每个分享链接只生成一份，默认使用**主用域名**（如 `ceshi.ycyingchen.top:23666`）
- 其余域名为备用：用户打不开主用域名时，可在分享页切换到备用域名（内网 `192.168.1.7:8080`、公网 `ceshi.202693.xyz`）
- 域名管理弹层：主用域名（测试访问、HTTPS、已验证）、备用域名列表（拖拽排序、设为默认、移除）、添加域名（`example.com` 或 `1.2.3.4:8080`）、保存
- 分享记录只存路径与参数，域名在生成链接时拼接，换域名不需要改历史分享

## 九、自定义背景

设置 → 外观 → 背景：

- **上传**：点击或拖入图片，接受 PNG / JPG / WebP，单张 ≤ 10 MB
- **当前壁纸**：120×68 缩略图 + 「移除」
- **背景模糊**：0–24 px 滑块，默认 12 px
- 内容区使用半透明面板叠在壁纸上，保证文字对比度；列表行、详情面板的透明度随主题切换（浅色 82%，深色 76%）
- 存储：图片存到用户偏好（`preferences` 接口），只保存文件引用与模糊值；换设备登录后同步回来
- 性能：壁纸按屏幕尺寸缩放后缓存，原图不参与渲染

## 十、弹层与交互

**右键菜单**：打开 / 快速预览 / 下载 ｜ 重命名（F2）/ 复制到（Ctrl+C）/ 移动到（Ctrl+X）｜ 分享链接 / 添加标签 ｜ 删除（Del，红色）。快捷键右对齐灰色显示。

**新建分享**（桌面对话框 / 移动底部抽屉）：文件信息 → 分享域名（主用选中、备用可选）→ 有效期（1 天 / 7 天 / 30 天 / 永久）→ 访问权限（在线预览、下载原文件两个开关）→ 访问密码（可选）→ 生成链接。

**标签编辑**：标签名输入、六色选择（选中色带外环）、下方实时预览 pill。

**命令面板（Ctrl+K）**：搜索框 + 分组结果（跳转 / 操作 / 标签），首项高亮，Enter 执行、ESC 关闭。

**账号设置**：用户卡片（头像、名称、角色、加入时间）、修改密码（当前 / 新 / 确认）、登录设备（当前设备、其他设备、退出其他所有设备）。

## 十一、状态与双栏

**状态（两端共用文案与按钮）**

| 状态 | 标题 | 说明 | 按钮 |
|---|---|---|---|
| 空文件夹 | 这个文件夹是空的 | 上传文件或新建文件夹，开始整理这里 | 上传文件 |
| 搜索无结果 | 没有找到匹配的文件 | 试试其他关键词，或检查当前的标签筛选 | 清除筛选 |
| 加载中 | 正在加载… | 大文件夹第一次打开会慢一点，之后就快了 | 进度条 |
| 无权限 / 错误 | 无法访问这个位置 | 权限不足，或与 NAS 的连接已断开 | 重试 |

**双栏**

- 桌面：左右两栏，中间是方向按钮与「同步滚动」状态
- 移动：**左右两栏，与桌面一致**——左栏源目录、右栏目标目录；两栏之间只有一条 1px 分隔线，不放按钮；两栏各自有独立的路径栏；底部显示「已选 N 项 + 移动 / 复制」
- 手机竖屏每栏约 195px，列表项用 22px 图标 + 11px 文件名，超长省略
- 移动端用长按选择文件，桌面用右键或 Ctrl 多选，搬运动作一致

## 十二、双端同步规则（必须遵守）

**桌面端每新增或修改一个界面 / 功能，必须同时补齐移动端对应形态，不允许只出一端。**

| 桌面形态 | 移动端对应 |
|---|---|
| 居中对话框 | 底部抽屉（顶部圆角 + 拖拽把手） |
| 右键菜单 | 长按操作表（九宫格 + 取消） |
| 侧边导航 / 设置左栏 | 设置列表 + 子页（返回按钮） |
| 表格 / 多列列表 | 卡片列表（名称 + 副信息 + 状态） |
| 悬浮工具条 | 底部固定操作条 |
| 快捷键提示 | 手势提示或无（移动端不显示键盘快捷键） |

其他要求：

- 同一功能的字段、默认值、状态标签在两端必须一致
- 空状态、错误状态、加载状态两端都要设计
- 移动端文案可缩短（如「分享管理」保持全称，「设置」子项可用简称），但不能改变含义
- 两端共用同一套色板、圆角、间距
